# Article artifacts

This directory contains manuscript-ready artifacts derived from the audited
release-candidate capacity-priority configuration (`method_version: 1.1.0`). The artifacts are
descriptive views of the existing method: they do not change source data,
indicator construction, normalization, weights, scores, ranks, or robustness
profiles.

- `figure_01_framework_architecture.svg`: editable vector version of the
  framework architecture, in English for the international manuscript.
- `table_01_indicators_sources.csv`: machine-readable master table of active
  indicators, operational definitions, sources, directions, and coverage.
- `table_01_indicators_sources.md`: manuscript-oriented rendering and notes.
- `table_02_scenario_design.csv`: machine-readable design of the 12 transport
  scenarios and four macro-weight schemes.
- `table_02_scenario_design.md`: manuscript-oriented rendering of the complete
  48-configuration factorial design.
- `table_03_robustness_summary.csv`: machine-readable scenario-agreement,
  municipal-profile, dimension-diagnostic, and reconstruction summary.
- `table_03_robustness_summary.md`: manuscript-oriented robustness table based
  on all 144 municipalities and the complete 48-configuration design.
- `figures/figure_02_stability_profiles.*`: aggregate distribution of the four
  municipal stability profiles.
- `figures/figure_03_scenario_agreement.*`: ranking, top-quartile, and rank-shift
  agreement across the 47 alternatives to the interpretive reference.
- `figures/figure_04_dimension_composition.*`: distributions of mean weighted
  contributions and municipality-complete dominant-dimension frequencies.
- `figures/figure_05_statewide_top_quartile_frequency.*`: municipality-complete
  choropleth of top-quartile frequency across all 48 configurations, using the
  official IBGE 2022 Municipal Digital Mesh only for visualization.

Figures 2--5 are reproducibly generated by
`python scripts/build_article_figures.py` after installing the article extras
with `pip install -e ".[article]"`. Editable SVG versions are retained in the
repository, and the same command exports 300-dpi PNG versions for manuscript
production.

The police series for 2022--2025 and the population field remain preserved in
the integrated municipal matrix but are not criteria in this framework.
